The real thing: the Stark VARG owner's manual

Two pages of the real manual (dark design, custom typeface, a table of contents with page numbers), translated in Quality mode. Pick a language.

"Stark", "Stark VARG" and "Stark Future" were detected as brand names and kept as written in every language. Scores are the run's own report: translation quality from the reviewer agent, layout from reading the written PDF back.

How it works

  1. ReadText blocks with their position, size, colour, alignment and font; images and drawings stay where they are. Scanned pages go through OCR.
  2. AnalyseSource language, tone and domain, brand and product names that must not be translated, and a short glossary of the terms a generic translator gets wrong.
  3. TranslatePage by page, in parallel, with the glossary and a length budget for each box, so the text is written to fit instead of squeezed afterwards.
  4. CheckEvery block is laid out in the real PDF engine and measured: overflow, shrinking, collisions with neighbours, missing glyphs. A reviewer agent scores the translation with MQM.
  5. Fix and reportFailing blocks go back to a refiner that checks its own fit; stubborn ones go to a stronger model that sees the page image. What is left becomes a decision for you.

Features

Layout preserved

Same position, size, colour and alignment. Text grows into free space, shrinks within limits you choose, and keeps line breaks, bold, italics and underlines.

The original fonts

Embedded fonts are rebuilt and reused. Missing accented letters (Ä, Ö, Ü) are assembled from the font's own glyphs; subsets are completed with the full font of the same family.

No overlapping text

The written PDF is read back. Text that collides with another block fails the document in both modes, with the exact block to fix.

Brands and jargon

"Stark" stays Stark, not "strong". Product names, codes and URLs are copied verbatim, and domain slang follows a glossary you can edit before a redo.

Two honest scores

Translation quality and layout fidelity, reported separately. The headline is the lower of the two, so a beautiful page with a wrong sentence does not pass.

Fast or Quality

Fast is cheap and good for understanding a document. Quality checks styling thoroughly, escalates hard blocks to a stronger model and fixes layout mismatches.

Review and redo

Each remaining problem comes with options (another font, keep a term, allow more shrinking) and a token estimate. Redo reprocesses only what changed, as a new version.

Cost and time, visible

Tokens, cost, requests and time per agent, stage and page, with interactive charts. Font fixes and layout checks cost zero tokens.

Built for long jobs

Translations run on a queue with separate workers: live progress, retries after a crash or redeploy, cancel any time, history kept across restarts.

Right-to-left and CJK

Arabic and Hebrew are mirrored and shaped; Chinese, Japanese and Korean get a CJK font embedded once for the whole document.

An MCP server for agents

Other agents can translate documents through MCP, with progress streamed over SSE while they wait. See below.

Observable

An admin page for the queue and workers, Prometheus metrics with a ready Grafana dashboard, and the agent traces in the OpenAI dashboard.

For agents: an MCP server

Point any MCP client at /mcp (Streamable HTTP, bearer token). A translation takes seconds to minutes, so the tools follow a job pattern that works in every client, with progress on the response's SSE stream.

  • translate_pdf starts a job from a public URL, an upload, a small base64 file or a sample.
  • wait_for_translation streams progress (step, page, percent) until the job ends.
  • get_translation returns the scores, the issues to review, the cost and the download link.
  • cancel_translation, list_languages, list_samples.
MCP client configuration
{
  "mcpServers": {
    "pdf-translator": {
      "type": "http",
      "url": "https://pdf-translator.coffee.jperelli.com/mcp",
      "headers": { "Authorization": "Bearer <MCP_TOKEN>" }
    }
  }
}

What it does not do (yet)

  • Rotated and vertical text is left as it is.
  • Inside one paragraph, mixed colours or sizes take the dominant style (bold and italic are kept).
  • Font subsets whose letters cannot be read or completed fall back to the closest generic family; the Review tab tells you which blocks and offers similar fonts.
  • A retried job starts again from page 1.
